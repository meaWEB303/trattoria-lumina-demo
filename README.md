# Trattoria Lumina — demo commerciale

Sito statico responsive, realizzato con HTML, CSS e JavaScript senza dipendenze di build. Per visualizzarlo, apri `index.html` in un browser oppure servi questa cartella con un server statico.

## Personalizzazione prima della pubblicazione

- Sostituisci indirizzo, telefono, email e orari dimostrativi con dati verificati.
- Aggiorna piatti, descrizioni e prezzi nel markup di `index.html`.
- Collega il modulo di prenotazione a un backend o a un servizio esterno. Attualmente mostra un avviso: non invia né salva dati e non conferma tavoli.
- Verifica ingredienti e allergeni con il ristorante prima di pubblicarli.
- Le fotografie in `assets/` sono immagini dimostrative create per questa demo; sostituiscile con fotografie approvate dal ristorante.
- Dopo aver scelto dominio e sede, aggiorna i metadati social con l'URL assoluto dell'immagine e i riferimenti locali verificati.
- I font Cormorant Garamond e DM Sans vengono caricati da Google Fonts; in assenza di connessione sono previsti font di sistema di riserva.

Non sono stati aggiunti mappa, collegamenti social, pagine legali o dati strutturati perché non ci sono informazioni verificate da usare.
